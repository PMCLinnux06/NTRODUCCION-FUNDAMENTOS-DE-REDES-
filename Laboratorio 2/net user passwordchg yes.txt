===============================================================================
11. COMANDO: net user [Usuario] /passwordchg:yes
===============================================================================

11.1. ¿PARA QUÉ SIRVE ESTE COMANDO?
Concede la autorización para que el usuario pueda cambiar su propia contraseña cuando lo desee.

11.2. SINTAXIS EXACTA:
net user Juan /passwordchg:yes

11.3. CAPTURA DE PANTALLA SIMULADA DE CONSOLA (OUTPUT):
+-----------------------------------------------------------------------------+
| C:\Windows\system32>net user Juan /passwordchg:yes                          |
|                                                                             |
| Se ha completado el comando correctamente.                                  |
+-----------------------------------------------------------------------------+

11.4. DESGLOSE DETALLADO Y EXPLICACIÓN DE CADA CAMPO MOSTRADO:

* /passwordchg:yes:
  - Activa el derecho de automodificación de credencial en el perfil del usuario.

11.5. ANÁLISIS DE CONFIDENCIALIDAD Y CIBERSEGURIDAD:
* Nivel de Riesgo: No confidencial.
