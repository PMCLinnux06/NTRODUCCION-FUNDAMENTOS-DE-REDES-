===============================================================================
1. COMANDO: ipconfig /all
===============================================================================

1.1. ¿PARA QUÉ SIRVE ESTE COMANDO?
Muestra la configuración TCP/IP completa y detallada de todas las interfaces de red (físicas, inalámbricas y adaptadores virtuales/VPN) presentes en la máquina. Revela parámetros críticos como direcciones MAC, direcciones IPv4/IPv6 asignadas, estado del cliente DHCP, tiempos de arrendamiento de IP y la jerarquía de servidores DNS locales y públicos.

1.2. SINTAXIS EXACTA:
ipconfig /all

1.4. DESGLOSE DETALLADO Y EXPLICACIÓN DE CADA CAMPO MOSTRADO:
* ipconfig: Comando base ejecutable encargado de consultar las variables del stack TCP/IP en el kernel de Windows.
* /all: Parámetro de extensión que fuerza al comando a leer el registro profundo de red (HKLM\SYSTEM\CurrentControlSet\Services\Tcpip\Parameters).
* Dirección física (MAC): Identificador único de 48 bits grabado en la EEPROM de la NIC (Capa 2 del modelo OSI).
* Dirección IPv4: Dirección lógica de 32 bits asignada al equipo para la comunicación en capa de red (Capa 3 OSI).
* Puerta de enlace predeterminada: IP del enrutador o Gateway hacia el cual se redirigen los paquetes cuya red destino es desconocida localmente.
* Servidores DNS: IPs de las entidades encargadas de resolver nombres FQDN a direcciones IP asociadas.

1.5. ANÁLISIS DE CONFIDENCIALIDAD Y CIBERSEGURIDAD:
* Nivel de Riesgo: Confidencial / Sensible.
* Razón de Ciberseguridad: Proporciona la infraestructura base requerida por un atacante en la fase de reconocimiento activo. Permite identificar la subred objetivo, la existencia de servidores DNS maliciosos (DNS Hijacking) o adaptadores virtuales no autorizados instalados por troyanos.
