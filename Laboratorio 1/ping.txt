Comando: ping
1. ¿Qué es y para qué sirve?
Es una herramienta de diagnóstico que envía paquetes de prueba (ICMP) a una dirección IP o dominio para verificar si está activo, si responde y cuánta latencia hay en la conexión.

2. Variaciones del comando:
ping [IP o Dominio]: Prueba básica enviando 4 paquetes (ejemplo: ping google.com o ping 10.0.0.1).

ping -t [IP]: Hace un ping continuo sin detenerse hasta que presiones Ctrl + C.

ping -n [Número] [IP]: Envía una cantidad específica de paquetes en lugar de los 4 por defecto.

ping -l [Tamaño] [IP]: Cambia el tamaño de los datos de prueba enviados (en bytes).

4. 📝 Desglose de lo subrayado y Confidencialidad:
🔴 Haciendo ping a google.com [IP] con 32 bytes de datos:

Qué es: Indica el destino consultado, la IP a la que se tradujo el nombre y el tamaño del paquete enviado.

Confidencialidad: 🟢 No confidencial (si es un sitio web público o IP local) / 🚨 Confidencial (si es la IP pública privada de un servidor personal o cliente).

🔴 Respuesta desde [IP] : bytes=32 tiempo=24ms TTL=117:

Qué es: Muestra la velocidad de respuesta en milisegundos (tiempo) y el contador de vida del paquete (TTL).

Confidencialidad: 🟢 No confidencial.

🔴 Paquetes: enviados = 4, recibidos = 4, perdidos = 0:

Qué es: Resumen que indica si la señal está estable o si hay pérdida de datos.

Confidencialidad: 🟢 No confidencial.

🔴 Mínimo = 22ms, Máximo = 25ms, Media = 23ms:

Qué es: Promedio de latencia de la red.

Confidencialidad: 🟢 No confidencial.
