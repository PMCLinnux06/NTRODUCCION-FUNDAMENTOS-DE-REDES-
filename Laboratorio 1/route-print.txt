Comando 8: route
1. ¿Qué es y para qué sirve?
Manipula y muestra las tablas de enrutamiento IP del sistema operativo. Le dice a Windows por cuál interfaz o puerta de enlace debe enviar los paquetes de datos según la dirección IP de destino.

2. Variaciones del comando:
route print: Muestra la tabla de enrutamiento IPv4 e IPv6 completa.

route add [Red_Destino] mask [Máscara] [Gateway]: Agrega una ruta estática manual a la tabla.

route delete [Red_Destino]: Elimina una ruta específica de la tabla.


4. 📝 Desglose de lo subrayado y Confidencialidad:
🔴 Lista de interfaces:

Qué es: Muestra el número asignado a cada tarjeta de red en el sistema y su dirección MAC física.

Confidencialidad: 🚨 CONFIDENCIAL. Contiene la MAC física de tu tarjeta.

🔴 Destino de red 0.0.0.0 con Máscara 0.0.0.0:

Qué es: Es la Ruta por Defecto (Default Route). Todo el tráfico que va hacia Internet y no pertenezca a la red local se envía a la Puerta de enlace (10.0.0.1).

Confidencialidad: 🟢 No confidencial.

🔴 Métrica:

Qué es: Un costo numérico que asigna Windows para elegir cuál interfaz usar si hay múltiples conexiones activas (a menor número, mayor prioridad).

Confidencialidad: 🟢 No confidencial.
